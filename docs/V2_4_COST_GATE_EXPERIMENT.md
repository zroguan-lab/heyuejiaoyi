# V2.4 Demo成本门控实验（M7实验1）

## 目标与证据

V2.3冻结114笔历史基线中，预估总成本在0.20R以内的53笔净盈利6.416U、平均Net R为0.117R、PF为1.128；超过0.20R的61笔净亏损8.288U、平均Net R为-0.170R、PF为0.735。这是V2.4当前最强且有明确经济含义的单变量假设。

该结果只来自3.64天的同一批样本，因此不能被当作已证明Edge。V2.4的任务是用后续样本证伪或证实这个假设，不是让原114笔历史变得更好看。

## 唯一改动

- V2.4沿用冻结对照组的Pre-Move候选、爆发/方向评分和55/70分双层门槛。
- 结构+ATR止损、TP1=1.5R平半仓、随后移保本、TP2=2.5R全部不变。
- 相关性、持仓数和本地总风险不新增执行限制。
- 只在V2 Demo显式晋级边界增加：`totalCostR > 0.20` 时硬拒绝Binance Demo入场。
- 边界值0.20R允许入场；只有严格大于0.20R才拒绝。

总成本R由预估双边手续费、滑点、点差以及对当前方向不利的Funding换算而来。

## 分账与可审计性

```text
V2.4信号/评分
  -> 后台研究账本（高成本也保留）
  -> V2.4 Demo成本门
       -> <=0.20R：允许继续执行安全预检
       -> >0.20R：记录原因，禁止准备/提交订单
```

V2.4是唯一当前运行版本，并使用独立Demo策略版本和绩效纪元。V2.3已冻结的114笔基线仍可通过 `npm run report:v2.3-demo` 按原截止时间和样本哈希复现，但只作为历史对照，不允许产生新信号或与V2.4混算。

## 验收

V2.4不因为代码上线就算实验成功。至少必须同时满足：

1. 高成本信号实际不能创建Demo执行计划，但研究账本仍能结算其反事实结果。
2. Pre-Move信号规则和止盈止损回归测试不变。
3. M5完成后，在未打开封存集的样本外窗口运行单变量对照。
4. 新Demo前向样本运行不少于30天且100笔已结算交易。
5. 扣除所有成本后，PF不低于1.20、平均Net R大于0.10R、最大回撤低于10%，且单币/单一市场事件利润集中度分别低于20%/25%。

未通过时，回滚边界是V2.4成本门控规则；V2.3的114笔冻结历史基线不受影响，但不会恢复为当前运行版本。
